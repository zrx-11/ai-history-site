# AI 纪元 · 人工智能通识一览

多页交互式站点：从 AI 发展史到 LLM / Agent / 蒸馏 / RAG / MoE / 多模态 / AGI / Harness 的完整通识知识库。

## 内容来源

- 抖音图文《AI发展史极简速览》（我不会AI啊 账号）37 帧星空风格关键帧逐帧提取，对应 24 个历史节点
- 前史、人物、术语、数据与治理等板块内容经公开资料网络核验补充
- 共 500+ 板块、18 篇经典论文、15 位关键人物、40 余条大事年表

## 使用方式

- 本地：直接打开 `index.html`（各页通过相对路径引用 assets 与 pages，需保持目录结构）
- 部署：推送到 GitHub 仓库后，在仓库 Settings → Pages 选择分支（main）即可在线访问

## 交互说明

- 顶部导航栏：8 大分类 + 首页，各页互跳
- 右上角 ☰：侧滑目录（首页），含搜索过滤
- 每页顶部「本页目录」：折叠板块索引，点击平滑跳转
- 底部「当前位置」条：上一节 / 下一节 / 回顶
- 时间线节点、人物卡、画廊图片均可点击查看详情或放大

## 技术说明

- 原生 HTML/CSS/JS，无外部依赖、无 CDN，离线可用
- 由 15MB 单文件版本拆解为多页工程（拆解脚本：`_expand/split_site.py`）
- 拆解时同步修复了原单文件中板块数据被误写入 `<style>` 导致浏览器不渲染的问题——拆解后板块内容以静态 HTML 输出，内容真实可见
